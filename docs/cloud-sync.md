# 云盘同步（WebDAV）

## 配置

在顶部“更多”菜单或状态栏的云盘状态处打开“云盘同步设置”：

| 设置 | 说明 |
| --- | --- |
| 服务器目录 URL | 一个 WebDAV **目录** URL，末尾斜杠会自动补全；例如 `https://dav.example.com/remote.php/dav/files/me/Qingwen/` |
| 用户名 | 保存在系统钥匙串 |
| 密码 | 保存在系统钥匙串；保存后留空表示保持原密码 |
| 本地自动保存间隔 | 默认 60 秒；0 表示关闭本地文件自动保存 |
| 云盘自动上传间隔 | 默认 300 秒；0 表示关闭自动上传 |

目录需要先在 WebDAV 服务器上创建。每个文档按下面的规则映射为远程文件：

- 标签页已有本地路径：使用本地文件名（例如 `笔记.lwd`）。
- 尚未保存到本地：使用标签页标题 + `.lwd`。

文件名会做 URL 编码。不同标签页如果标题相同且都未保存到本地，会映射到同一个远程文件，请避免这种命名冲突。

## 手动操作

顶部“更多”菜单：

- **上传当前文档到云盘**：用当前编辑器内容覆盖远程同名 `.lwd`。
- **从云盘下载并覆盖当前文档**：下载远程 `.lwd`，替换当前编辑器内容；如果当前标签页已有本地路径，同时原子覆盖本地文件。

上传使用 HTTP `PUT`（覆盖式），下载使用 `GET`。WebDAV 目录不会自动创建。

## 自动行为

- **本地自动保存**：默认 60 秒。每隔该间隔检查所有已有路径且未保存的标签页，后台异步写回本地 `.lwd`；可在设置中调整或关闭。
- **云盘自动上传**：默认 300 秒。只对**当前标签页**检查，只有该标签页的修订号大于上次成功上传的修订号时才上传；没有本地变更不会重复上传。
- 两个计时器完全解耦：本地保存失败不影响云盘上传，云盘失败不影响本地保存。
- 云盘上传失败只在状态栏显示原因，不弹窗；下个上传间隔会再次尝试。成功上传后更新“已同步”时间。

## 状态栏

| 状态 | 含义 |
| --- | --- |
| 云盘未配置 | 没有设置服务器 URL |
| 云盘已配置 | 已配置，但当前标签页还没有上传记录 |
| 云盘同步中… | 正在上传或下载 |
| 云盘已同步 HH:mm | 最近一次成功同步 |
| 云盘失败：原因 | 最近一次失败；会在下个间隔重试 |

点击状态栏的云盘状态可直接打开设置。

## 凭据安全

- 用户名和密码作为一个 JSON 凭据块写入**系统钥匙串**：
  - Windows：Credential Manager
  - macOS：Keychain
  - Linux：Secret Service（需要桌面密钥环服务）
- `appDataDir/sync.json` 只保存服务器 URL 和两个间隔，不保存用户名/密码。
- 不会把凭据写入日志；网络错误信息只包含 URL/HTTP 状态，不包含 Authorization 头。
- 设置面板可以清除系统钥匙串中的凭据。
- 目前使用 HTTP Basic Auth；HTTP URL 不会被拒绝，但凭据会以可被中间人截获的方式传输，生产环境应使用 HTTPS。
- 不支持 OAuth、客户端证书、代理认证或自签名证书的单独信任配置。

## 限制

- 自动上传只覆盖当前标签页，不后台批量上传其他标签页。
- 覆盖式同步，没有远程版本历史、冲突合并或“远程更新”检测。
- WebDAV 目录必须已存在；不会自动 `MKCOL`。
- 不处理远程文件名冲突；同标题未保存文档可能互相覆盖。
- 下载会立即覆盖当前编辑器内容和已有本地文件，操作前请确认远程文件正确。
