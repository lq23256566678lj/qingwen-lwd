# 本地默认保存文件夹

这是不使用 WebDAV 时的简化保存方式：应用只把 `.lwd` 文件写到本地文件夹，不做任何网络请求。可以把该文件选择为 OneDrive、坚果云、百度网盘等客户端的**本地同步目录**，由同步客户端负责上传。

## 设置

打开“更多 → 云盘同步设置”（或点击状态栏云盘状态），在顶部选择：

**默认保存文件夹（不使用 WebDAV 时）**

- 点击“选择…”选择一个已存在的本地文件夹。
- 点击“清除”取消默认保存文件夹。
- 设置保存到 `appDataDir/sync.json` 的 `defaultSaveDir` 字段；它不是凭据，可以明文保存。
- 文件夹必须是绝对路径且已存在；应用不会自动创建文件夹。

## 生效条件

只有同时满足以下条件时，本地默认保存逻辑才启用：

1. **WebDAV 服务器目录 URL 为空**（没有启用云盘同步）。
2. 已选择默认保存文件夹。

如果配置了 WebDAV URL，新建文档不会自动写入默认文件夹，仍按 WebDAV 流程处理。

## 新建文档

启用后，新建根标签页或子标签页会：

1. 在默认文件夹中静默创建一个 `.lwd` 文件；
2. 文件名取文档标题：
   - 新标签页初始标题为 `未命名文档`，文件为 `未命名文档.lwd`；
   - 如果同名文件已存在，自动使用 `未命名文档 2.lwd`、`未命名文档 3.lwd`，标签页标题同步为对应文件名；
3. 不需要“保存”对话框，也不访问网络。

## 自动保存

- 默认每 60 秒检查所有已有路径且未保存的标签页，后台异步写回本地 `.lwd`；可在设置中改为其他秒数或 0（关闭）。
- 会话快照仍按约 1.1 秒的节流写入 `recovery/session.json`，用于崩溃/断电恢复；它不是最终 `.lwd` 文件。
- 新建时若编辑器内容在写入期间又有变化，标签页会标记为未保存，下个自动保存周期继续写回。

## 标题与文件名

- 标题会先做 Windows 文件名安全处理：替换 `< > : " / \ | ? *` 和控制字符，去掉结尾的点和空格，保留 `CON`、`PRN` 等保留名时加 `_` 前缀。
- 文档重命名时，如果文件位于默认保存文件夹内，会同时重命名本地文件，并更新 `.lwd` 里的 `meta.title`；同名冲突时自动加序号，标签页标题同步更新。
- 通过“另存为”保存到其他目录的文档，不再跟随默认文件夹的文件名重命名。
- 默认文件夹中的文件名不会递归创建子目录；所有文档平铺在该文件夹下。

## 与 WebDAV 的关系

- 两种方式可以同时配置，但**新建/自动落盘只由 WebDAV URL 是否为空决定**：
  - URL 为空 + 文件夹已选：本地默认为主，所有新建文档自动落盘；
  - URL 非空：使用 WebDAV 同步逻辑，不自动写入默认文件夹。
- 已经存在于默认文件夹中的 `.lwd` 即使之后配置 WebDAV，仍会按普通本地文件自动保存。

## 限制

- 不监听云同步客户端的上传状态；文件是否已上传由 OneDrive/坚果云/百度网盘决定。
- 不处理同步冲突；若云客户端同时修改同一文件，仍可能出现“最后写入者获胜”。
- 不同标题经过安全处理后可能相同，会用数字后缀避免覆盖。
- 文件夹被移动、删除或没有写权限时，新文件创建/自动保存会在界面提示失败，不会退回其他目录。
